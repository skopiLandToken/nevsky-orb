# Nevsky ORB

Nevsky ORB stands for **Operational Relationship Brain**.

Nevsky is the Telegram-first operational brain for SKOpi and future white-label deployments. It sits between communications, tasks, reminders, approvals, platform events, and people.

## Core idea

Nevsky is not just a CRM.
It is an ORB:
- communication routing
- operational memory
- task and reminder coordination
- approvals and audit trail
- project and workday planning
- relationship intelligence

## Current repo structure

- `docs/` core source material
- `notes/` build notes, bug notes, handoff notes
- `decisions/` long-term decision records
- `changes/` changelog
- `app/` FastAPI app and worker
- `postgres-init/` database bootstrap SQL
